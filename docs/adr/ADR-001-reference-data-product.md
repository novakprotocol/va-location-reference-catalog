# ADR-001 — Reference Data Product, Not Spreadsheet

## Status

Accepted for pilot.

## Decision

Treat the Public VA Facility Location Catalog as a reference-data product.

## Rationale

A spreadsheet is easy to create but hard to govern.

A data product can have schema, lineage, validation, review, releases, and consumer contracts.

## Consequence

More up-front structure, much safer downstream adoption.
